# Run code with a temporary configuration

Run code with a temporary configuration

## Usage

``` r
with_manim_config(settings, code)
```

## Arguments

- settings:

  A named list passed to
  [`manim_config()`](https://adamrsophie.github.io/manimR/reference/manim_config.md).

- code:

  Code to evaluate.

## Value

The value of `code`.
