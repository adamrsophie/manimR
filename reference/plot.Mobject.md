# Plot a mobject

Draws a mobject on the current graphics device, framed like a scene, so
it shows in the RStudio Plots pane.

## Usage

``` r
# S3 method for class 'Mobject'
plot(x, background_color = cfg("background_color"), ...)
```

## Arguments

- x:

  A mobject.

- background_color:

  Background color.

- ...:

  Ignored.
