# Section types

Upstream's `DefaultSectionType`, for the `section_type` argument of a
scene's `next_section()`:
`self$next_section("intro", DefaultSectionType$NORMAL)`. Any string
works; the type is written to the sections index for tools such as
presentation players.

## Usage

``` r
DefaultSectionType
```

## Format

A named list of strings.

## Value

A named list of section type names.
