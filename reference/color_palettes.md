# Named color palettes

Named lists of colors from Manim's color modules: `X11_COLORS` (Manim's
`X11`), `XKCD`, `SVGNAMES`, `DVIPSNAMES`, `AS2700` and `BS381`. Use them
like `XKCD$AVOCADO`.

## Usage

``` r
X11_COLORS

XKCD

SVGNAMES

DVIPSNAMES

AS2700

BS381
```

## Examples

``` r
Circle(color = XKCD$AVOCADO)
#> <Circle> 32 points, 0 submobjects
```
