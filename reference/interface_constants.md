# Interface constants

Upstream's command line messages (`SCENE_NOT_FOUND_MESSAGE` and so on,
with [`{}`](https://rdrr.io/r/base/Paren.html) where upstream formats in
a scene name), the help epilog and context settings, the key codes of
Shift and Ctrl used by interactive scenes, the default window position
(`START_X`, `START_Y`), and `RendererType`, the values the `renderer`
setting accepts.

## Usage

``` r
SCENE_NOT_FOUND_MESSAGE

CHOOSE_NUMBER_MESSAGE

INVALID_NUMBER_MESSAGE

NO_SCENE_MESSAGE

EPILOG

CONTEXT_SETTINGS

SHIFT_VALUE

CTRL_VALUE

START_X

START_Y

RendererType
```

## Format

Strings, numbers, or named lists.
